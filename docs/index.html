if you care where your data goes

Your token and indexstay on your computer.

The plugin calls no AI service. What Claude reads to answer you goes to Anthropic in your Claude Code conversation, like anything you show Claude.

Token in your keychain

Claude Code stores your Canvas access token in the system keychain, not in a file.

Index on your disk

Course files and the search index live in ~/.claude/plugins/data/. Uninstalling deletes them.

Read-only Canvas

It reads your courses, files, assignments and grades with your token. It never writes to Canvas.

Keeps itself current

If a course's last sync is over 6 hours old, it re-reads only what changed, in the background.

No subscription.Nothing hidden.

Questions

Does it work with my school?

Any school on Canvas. Setup asks for your Canvas URL, for example canvas.cmu.edu.

What does it cost?

Nothing. The plugin is free and MIT licensed. Answers use your existing Claude account.

Will it do my homework?

No. It explains the material and checks your attempt, but never writes graded work.

Windows?

Yes. Install Git for Windows first: Claude Code uses its shell to start the plugin.
